# mylib-mocha-chai

A small JavaScript library (`mylib`) with basic arithmetic functions, a main program that uses it, and a Mocha + Chai unit test suite.

## Requirements

- Node.js 18 or newer
- npm

## Installation

```bash
git clone https://github.com/koiri143/mylib-mocha-chai.git
cd mylib-mocha-chai
npm install
```

## Usage

Run the main program:

```bash
npm start
```

Run only the unit tests (without the main program):

```bash
npm test
```

## Project structure

```
mylib.js              the library (add, subtract, multiply, divide)
main.js               main program that imports mylib
tests/mylib.test.js   Mocha + Chai unit tests
```
